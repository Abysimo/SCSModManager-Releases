# SCS Mod Manager

An unofficial utility for managing Euro Truck Simulator 2 (ETS2) and American Truck Simulator (ATS) mods.

SCS Mod Manager is not affiliated with, endorsed or sponsored by SCS Software.

Publisher: **Abysimo**, also known as **Abysmo** on gaming forums.

## Release status

The first public release is being prepared.
